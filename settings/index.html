GitHub PAT 配置

在这里配置你的 GitHub fine-grained PAT，用于一键精读和删除操作。
PAT 存储在浏览器 localStorage 中，不会上传到服务器。
需要权限：Actions: Read and write

如何创建 PAT

  1. 前往 GitHub Fine-grained tokens
  2. Repository access 选 gzy0005/zotero-arxiv-daily
  3. Permissions: Actions → Read and write
  4. 生成后复制 token，粘贴到上方输入框
